## Немного о настройке проекта
Для запуска приложения:
- Сначала подтянуть необходимые библиотеки `npm ci`.
- Далее для запуска приложения в режиме разработчика выполнить команду `npm run dev`.
- Если необходимо получить бандл, выполнить `npm run build`.

### Особенности проекта (что сделано)
- Загрузка элементов на странице с помощью темплейтов.
- Добавлена интерактивность:
    - Реализована работа со слушателями событий (слушатель клика, клавиш типа Esc и загрузка форм)
    - Настроено изменение состояний элементов по клику
    - Реализованы открывающиеся модальные окна с формами
    - Настроена клиентская валидация форм
- Реализован API (CRUD).
